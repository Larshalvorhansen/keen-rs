# Minsky-RS — Phase 1.4 (preservation-first XML)

Reference upstream Minsky commit: `06923f7e4df5d2bcbc67c5cf726ecc1d609da775`.

Extends the passing Phase 1.3.1 workspace. `minsky-format::PreservedDocument`
keeps original UTF-8 XML bytes unchanged until an explicitly supported edit.

- `from_bytes` / `open`: read and inspect schema 3, retaining the entire source.
- `as_bytes`: byte-for-byte identical round trip for unedited documents.
- `set_title`: narrowly scoped edit to a direct root `<Minsky><title>` plain-text
  element, XML-escaping inserted text; all other bytes remain untouched.
- `is_modified` / `changed_fields`: track modifications to the limited supported field.
- `write_new`: creates only a *new* file, refusing to overwrite an existing path.

This is **not** a general-purpose serializer. Unknown XML is preserved but not
understood. Never use this increment to edit Godley, Ravel, tensor, model IDs or
references. Root title edits with child XML/CDATA are rejected.

## Install and test on macOS / Nix

```sh
mv ~/Downloads/minsky-rs-phase1-4.zip ~/Documents/keen-rs/
cd ~/Documents/keen-rs
unzip -q minsky-rs-phase1-4.zip
cd minsky-rs-phase1-4
nix develop
cargo test --workspace
cargo run -p minsky-cli -- tests/fixtures/upstream/exponentialGrowth.mky
```

New tests: `crates/minsky-reference-tests/tests/xml_preservation.rs`.

No new Rust dependencies. Cargo.lock will be generated by Cargo as necessary.
